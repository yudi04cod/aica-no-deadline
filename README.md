This is my entry for make.fun's "One Line, No Deadline Met" bounty: one
short excuse for blowing a deadline, told in a single sentence. The
speaker pins the blame on their calendar app, which supposedly pushed
the deadline back a week in secret — and then confesses they simply
took the app at its word. No dog, no traffic jam, just blind faith in
a scheduling tool.

The whole thing is 111 characters long, comfortably inside the 200
character limit. `main.py` needs nothing beyond Python 3 and the
standard library, and every run writes the identical line to
`/output/entry.txt`, so the result is fully repeatable.

Built for the [make.fun](https://make.fun) competition
[u-markk-st-one-line-no-deadline-met-6adc00ce](https://make.fun/bounty/u-markk-st-one-line-no-deadline-met-6adc00ce).

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

To put `entry.txt` in a different folder, set `MAKEFUN_OUTPUT_DIR`
before running the script.
