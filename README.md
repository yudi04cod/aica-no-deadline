One funny excuse for missing a deadline for make.fun's "One Line, No
Deadline Met": a single line, under 200 characters — the calendar moved
the deadline to next week without telling me, and honestly I believed it.

`main.py` (Python 3, standard library only, deterministic) writes that
single line (111 characters) to `/output/entry.txt`.

Built for the [make.fun](https://make.fun) competition
[u-markk-st-one-line-no-deadline-met-6adc00ce](https://make.fun/bounty/u-markk-st-one-line-no-deadline-met-6adc00ce).

Referral code: 38m33ybw

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

Set `MAKEFUN_OUTPUT_DIR` to write `entry.txt` somewhere else.
